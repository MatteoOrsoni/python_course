# Introduction to Python for Data Analysis

An 8-hour introductory course designed for Psychology PhD students to learn fundamental Python programming and data analysis skills. This hands-on course covers everything from installing Python to performing descriptive analyses and creating visualizations.

## Course Overview

This course provides a comprehensive introduction to Python programming with a focus on practical data analysis applications. Students will learn to work with real datasets, perform statistical analyses, and create meaningful visualizations using industry-standard Python libraries.

## Learning Objectives

By the end of this course, students will be able to:
- Install and configure Python on their computer
- Create and run code using Jupyter Notebook
- Load and manipulate datasets using pandas
- Perform descriptive statistical analyses
- Create publication-quality visualizations
- Apply Python to real-world psychological research scenarios

## Prerequisites

No prior programming experience required. Students should bring a laptop and be comfortable installing software.

## Course Structure

**Duration:** 8 hours (typically delivered over 2 days or 4 sessions)

**Topics Covered:**
- Python installation and environment setup
- Introduction to Jupyter Notebook
- Python basics: variables, data types, and control structures
- Working with pandas for data manipulation
- Descriptive statistics and data exploration
- Data visualization with matplotlib and seaborn
- Final project: complete data analysis workflow

## Tools and Libraries

- Python 3.x
- Jupyter Notebook
- pandas
- NumPy
- matplotlib
- seaborn
